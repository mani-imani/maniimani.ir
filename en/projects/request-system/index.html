What was built

  • Workflow engine

    steps, conditional paths, parallel approval (all or any one), voting, return and referral, with seven ways to pick an assignee and automatic assignment to the least-loaded person or by rotation.

  • No-code tools

    a drag-and-drop form builder with 15+ field types (Persian date, signature, table, formula, conditional display) and a workflow designer with a live diagram.

  • Multi-company

    several companies on one installation, with full data isolation and a separate visual identity for each.

  • Sign-in and access

    Sign-in with Active Directory (LDAP) and role-based access control with 13 permissions, custom roles and per-person exceptions.

  • Deadlines

    calculated from the work week and Persian holidays, with reminders and overdue alerts.

  • Notifications

    in-app, email, Web Push and SMS.

  • Reports

    Excel export and Persian PDF with the company letterhead.

  • Interface

    fully Persian and right-to-left, mobile-friendly, installable as a PWA.

  • Security

    a strict CSP, private files behind signed links, login rate limiting, and sessions revoked on password change.

  • Quality

    359 automated backend tests, and 34 browser test scenarios with 1,000+ checks on desktop and mobile.

  • Deployment

    installs on a server with Docker Compose or directly with systemd, nightly backups with a tested restore, and a complete install and maintenance guide handed to the client.
