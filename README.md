## درباره‌ی این ریپو

این‌جا فقط خروجی ساخته‌شده‌ی سایت است: HTML و CSS ایستا، بدون فریم‌ورک و بدون سرور. صفحه‌ها بدون JavaScript هم خوانده می‌شوند؛ اسکریپت فقط برای تغییر پوسته، دکمه‌های کپی، پالت فرمان (کلید `/`) و نسخه‌ی آفلاین است.

فایل‌ها از یک منبع جدا ساخته می‌شوند. برای همین دستی ویرایش نمی‌شوند و هر به‌روزرسانی جای کل محتوا را می‌گیرد.

| مسیر | چیست |

| `index.html` · `en/` | صفحه‌ی اصلی، فارسی و انگلیسی |

| `manifest.webmanifest` · `sw.js` | نصب به‌شکل برنامه و نسخه‌ی آفلاین |
| `CNAME` · `.nojekyll` · `robots.txt` · `sitemap.xml` | تنظیم دامنه و موتورهای جست‌وجو |

میزبانی با GitHub Pages است و دامنه‌ی `maniimani.ir` از فایل `CNAME` می‌آید.

# maniimani.ir

Personal site of Mani ImaniSanjar (GeekMani): computer engineering student and web developer from Kermanshah, Iran.

## About this repo

This repository holds only the built site: static HTML and CSS, no framework, no server. Pages read fine without JavaScript; the script only adds the theme switch, copy buttons, a command palette (press `/`) and the offline copy.

The files are generated from a separate source, so they are not edited by hand; every update replaces the whole content. Hosted on GitHub Pages; the custom domain comes from `CNAME`.

Text, photos, the resume and the GeekMani mark belong to Mani ImaniSanjar. The Vazirmatn and JetBrains Mono fonts are included under the SIL Open Font License; each font folder in `fonts/` carries its license text.
